## Critério obrigatório por guia

1. Preservar o visual Quanton3D e o conteúdo correto já existente.
2. Corrigir causalidade, termos técnicos e recomendações inseguras.
3. Não publicar números universais de exposição, movimento, lavagem ou pós-cura.
4. Separar diagnóstico por evidência de tentativa aleatória.
5. Usar imagens pertinentes, texto alternativo e navegação interna válida.
6. Manter os recursos interativos úteis, sem apresentar índice didático como medição física.
7. Validar o arquivo com `npm run validate:guides -- /guias/nome-do-guia.html`, depois executar `npm run lint` e `npm run build`.
8. Publicar apenas os arquivos daquele ciclo e confirmar a versão no site.
